# Changelog

What the `rulebook` plugin ships, by version. semantic-release writes this file from the commit messages on
`main`; do not edit it by hand. Design work under `research/` and `review/` ships nothing and is not listed.

## 1.0.0 (2026-11-27)

The first release of the one-shape rulebook: every skill is a short procedure with notes files beside it, and no rule
has an ID.

* **skills** — agent, code, crq, grilling, migrations, obs, planning, playwright, skill-feedback, testing
* **crq** — a thin router that takes a ticket to a pull request for one developer, with five lanes by kind, a
  one-way-door flag and four stops
