# 31d v2 · Good/Bad — smoke / e2e rules (EA1–EA6, EB1–EB4, EC1–EC6, ED1–ED5)

Rewrite of `31d-good-bad-smoke.md` under brief `31-good-bad-v2-BRIEF.md` (GB1a). Source: agent-platform
`origin/master`, read via `git show` 2026-10-02. Paths are repo paths.

House rules every Good below obeys, besides its own rule:

| rule | as applied here |
|---|---|
| U2a / GA6 / GT1 | test title starts `should …` |
| ED1 / GT2 / GT4 | one `test.step('Given/When/Then …')` per step; `annotation: { type: 'issue', … }` |
| EA–ED | role locators, web-first matchers, no `networkidle`, no `.first()`, fixtures over `apiLogin` |
| ST2 | a call that does not fit one line: one argument per line, closing paren on the last argument's line |
| line length | 110 — `aruvii-ui/.prettierrc.json` `printWidth` (`.editorconfig` sets 120 for Java/Groovy only) |

Notes that apply throughout:
- **ST2 vs Prettier.** Prettier "hugs" a trailing object argument and puts `)` on its own line; ST2 does not. The Goods follow ST2. Nothing runs Prettier over `playwright/` today, so nothing enforces either shape.
- **Annotation ids.** Where the source spec names a work item (`#576`, `#163`) it is used. Where it cites only a REQ (`REQ-072 C07`) that is used and marked; swap for the owning `#NNN` when known.
- **Every real test Bad also breaks U2a + ED1** (no `should` title, no `test.step`, no annotation) — master has 0 `test.step` and 0 `annotation`. Not repeated per entry; "also breaks" lists only the other ids.
- `// …` marks lines elided for the 15-line cap; the elided lines are not part of the claim.
