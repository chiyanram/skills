# issues: archived local tracker

> **Archive.** These are the tickets of the first wayfinder map, [map.md](../map.md). On 2026-10-02 the map moved to
> GitHub issue [chiyanram/skills#9](https://github.com/chiyanram/skills/issues/9), and all work since then is in
> [GitHub issues](https://github.com/chiyanram/skills/issues). Do not add tickets here.

The files stay because research files and other repos cite them by path and line. Each ticket starts with a header
line:

```
Type: wayfinder:<research|grilling|prototype|task> · Status: open|closed · Assignee: · Blocked by:
```

Prefixes: **R** research, **G** grilling (a decision taken by question and answer with the operator), **P** prototype,
**D** design. A ticket still marked `open` here is not tracked here any more. The ticket index in #9 maps each code to its GitHub
issue: for example, D1 is [#21](https://github.com/chiyanram/skills/issues/21) and G9c is
[#34](https://github.com/chiyanram/skills/issues/34).
