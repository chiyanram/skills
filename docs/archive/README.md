# Design archive

This folder holds the design history behind the `rulebook` plugin: the research notes, the review-page builders and
pages, the first wayfinder map and its tickets, the scoped-reviewer prototype, the pinned reference repos, the early
requirements and design overview, and the builder test. Each file sits at its original path under `docs/archive/`.
The archive is frozen: nothing here is maintained, `make lint` does not check it, and its relative links may be
broken. To read a file at its old path, so that a `path:line` citation resolves exactly, check out the git tag
`design-archive-2026-11`, the last commit before the move. The live rule ledger and reference format are in
[`docs/rulebook/`](../rulebook/).
