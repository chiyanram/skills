# 4. Every reference has the same five sections

Status: accepted

## Context

A reader who does not know where a reference keeps its rules must read the whole file.

## Decision

Every reference has five sections, in this order: Rules · When X, use Y · Good / Bad · Decided edges · Review
checks. The template is [reference-format.md](../rulebook/reference-format.md).

## Consequences

- A reader knows where to look without reading the whole file.
- A rule that does not fit the shape is a sign that it is two rules or no rule.
