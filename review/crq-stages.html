Three lanes (stage 1 picks one)

quick

0 1 · 6 6a 7 8 9 10

docs or chore, size S

standard

0 1 2 3 · 5 · 6–10 (4 only if UI)

bug · chore/refactor M · S/M feature without UI

full

every stage

feature with UI · anything size L

Floor: migration, security, public API or a new dependency → at least standard. Stages 7 and 8 run in every lane.

Every stage

  • A skipped stage stays listed as skip: <reason>.
  • Rebase onto origin/master at spawn, before every verify and before done. Conflicts: resolving-merge-conflicts, module build before --continue; a behaviour-changing resolution is a decision for you.
  • A reversible question: take the default, continue, report it. A high-level one: stop; the coordinator relays it to you.
  • Status goes on GitLab through post-status: needs-decision · blocked · done.
